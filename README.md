# Mentor — лендинг

ref lead-relay: PPV9TUT355. Чистый HTML/CSS/JS, шрифты Unbounded + Onest, motion-kit (motion.css/js).

Идея: сетка из 100 звонков. «Как сейчас» слышно 10, «С Mentor» разобраны все, потерянные клиенты подсвечены. Та же сетка ведёт закреплённую сцену «четыре шага». Калькулятор тарифа считает по реальным ставкам 4 тарифов (2300 / 6000 / 13000 / 30000 минут).

Заглушки/примеры, подтвердить у клиента: фразы в карточках звонков (потерянный клиент, «Скажите: ...») иллюстративные. Цифры (+35%, 30 ч, 10 из 100, 150 000 ₽), цены, ответы FAQ и контакты взяты с salesmentor.ru. Политика и согласие ведут на страницы salesmentor.ru.
